# Image Upscaling Web App using CNN (ESPCN)

This project is a web application designed to enhance image resolution using a Convolutional Neural Network (ESPCN). Developed as part of a Bachelor's thesis at Taras Shevchenko National University of Kyiv, the system allows users to upload low-resolution images and upscale them efficiently while preserving quality.

## Features

- 📷 **Image upscaling using ESPCN** — Deep learning-based enhancement
- 🌐 **Web interface** — Built with Flask, HTML, and JavaScript
- 🖼️ **Noise removal** — Optional denoising via median filtering
- 🔧 **Configurable upscale factor**
- 💾 **Download enhanced images**

## Technologies Used

- **Python**, **Flask** – Backend
- **TensorFlow**, **NumPy**, **Pillow** – Image processing & ML
- **HTML/CSS/JavaScript** – Frontend
- **ESPCN (Efficient Sub-Pixel Convolutional Neural Network)** – Core image upscaling model


## Getting Started

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
4. Open in browser at `http://localhost:5000`
